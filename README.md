# 3D Graphics Engine 

A simple, fast, custom OpenGL based 3D engine. 
Fully custom model loading supporting glb, obj and glft.
Custom Shaders and lighting 



Dependencies 
- Open GL
- ASSIMP
- GLAD
- GLFW
- GLM
